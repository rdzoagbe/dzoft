    Sauvegardes et donnéesProtection et récupération des données À vérifier

    Sauvegarde rapide, depuis ce navigateur

    Enregistre en un fichier, dans votre Google Drive ou sur cet appareil, toutes vos données de gestion : clients, devis, factures et leur registre, paiements, avoirs, suppléments, messages, journal. Le fichier est chiffré ici avec le mot de passe que vous choisissez ; personne ne peut l’ouvrir sans lui, pas même DZOFT. Les codes d’accès secrets ne sont pas inclus. Les PDF archivés et les comptes de connexion restent couverts par la sauvegarde complète ci-dessous.

    …

    Relier Google Drive (une seule fois)

    Pour que le bouton « Sauvegarder sur Google Drive » envoie le fichier directement dans votre Drive, collez ici l’« ID client » créé dans votre compte Google Cloud (guide : relier Google Drive). La première fois, Google vous demande l’autorisation ; l’accès se limite aux fichiers créés par DZOFT, jamais au reste de votre Drive.

    Vérifier une sauvegarde

    Ouvre un fichier de sauvegarde avec son mot de passe et montre ce qu’il contient. Rien n’est envoyé ni modifié.

    Sauvegarde complète, depuis votre ordinateur Windows

    Sauvegarde récupérable : non vérifiée. La présence des données dans Supabase ne constitue pas une sauvegarde indépendante.

    Supabase Free ne fournit pas de sauvegardes automatiques gérées. Utilisez le script de sauvegarde chiffrée DZOFT sur votre ordinateur Windows, puis copiez et vérifiez l’archive sur un support indépendant. Les sauvegardes de la base ne contiennent pas les fichiers Storage.

    Sauvegarde locale sécurisée : ouvrez le guide, puis lancez l’outil Windows avec un dossier de destination hors du PC. Aucun mot de passe n’est transmis au site. Une restauration complète reste à vérifier sur un environnement isolé.
